# ADR 003 — Validação local reprodutível e documentação de deploy

* **Data:** 08 de junho de 2026
* **Status:** Aprovado
* **Responsáveis:** Isabella, Gabriel e Marcus

## 1. Contexto

O CineLog utiliza um backend Spring Boot com banco de dados H2 em memória e um frontend estático integrado ao servidor. Um deploy remoto permanente não estava disponível no repositório, e a criação de uma infraestrutura de homologação web dedicada exigiria tempo adicional e complexidade operacional fora do escopo desta sprint.

## 2. Decisão

Decidimos documentar e validar o MVP como um ambiente de homologação local reprodutível, em vez de depender exclusivamente de um deploy remoto. O processo de validação local é descrito em `docs/DEPLOY.md` e pode ser reproduzido a partir do repositório com os mesmos comandos em qualquer máquina que tenha Java 21 instalado.

## 3. Consequências

### Benefícios

* **Reprodutibilidade:** qualquer avaliador pode rodar o sistema com um único comando em `cinelog`.
* **Menor custo de setup:** não é necessário provisionar um servidor remoto ou um banco de dados externo.
* **Alinhamento com evidências:** o documento de deploy complementa a CI e torna a entrega mais transparente.

### Trade-offs

* **Persistência volátil:** o H2 em memória não mantém os dados entre reinicializações.
* **Ausência de staging remoto:** a demonstração de homologação depende de acesso local do avaliador.
* **Dependência direta do Java local:** exige Java 21 instalado na máquina do avaliador.
